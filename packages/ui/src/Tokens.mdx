# Design tokens

Every colour, typeface, size, space, radius and motion value in RIVR comes from one file,
`packages/tokens/tokens.json`. Style Dictionary generates the CSS custom properties, the Tailwind
theme, TypeScript constants, the Android colours and theme, and the PWA manifest colours from it.
Change the file, run `pnpm --filter @rivr/tokens build`, and every surface changes together.

In `@rivr/ui` the Tailwind theme holds only these values: `bg-surface`, `text-content-muted`,
`p-4`, `rounded-lg`, `text-16`. Tailwind's own palette and scale do not exist here.

## Rules

- Dark only. Flat surfaces separated by spacing and 1 px gold hairlines at 25%.
- Corner radius 6 px at most. One gold filled button per screen at most.
- Bodoni Moda only for display: TV titles, the jackpot figure, the wordmark; never below 20 px.
- Every number uses tabular figures. Money is `₹1,20,000`; time is the 24-hour IST clock.
- Motion only on state changes: 200 ms, ease-out.

## Type scale

Display face: Bodoni Moda, with Tiro Devanagari Hindi for the ₹ sign. 20 px and up.

## Spacing

A 4 px grid. Utilities use the step: `p-4` is 16 px, `gap-2` is 8 px.

<div style={{ display: 'flex', flexDirection: 'column', gap: tokens.space[2] }}>
  {Object.entries(tokens.space).map(([step, size]) => (
    <div key={step} style={{ display: 'flex', alignItems: 'center', gap: tokens.space[4] }}>
      <code style={{ width: tokens.space[32] }}>{`space.${step} · ${size} px`}</code>
      <div style={{ width: size, height: tokens.space[3], background: tokens.color.gold }} />
    </div>
  ))}
</div>

Touch targets on the player app and the dealer tablet are at least {tokens.size.touch} px.
