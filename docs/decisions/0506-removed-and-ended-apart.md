# 0506: Removed staff and ended promotions apart, and a wider Members list

Date: 8 Nov 2026 · The owner's requests of 8 Nov ("show the deleted staff / promotions separately"; more Members columns)

**Tabs in the address.** Removed staff is a third tab on Staff (`/staff?tab=removed`). Ended is a tab beside Current on Promotions (`/promotions?tab=ended`), each with its count. Both use `Tabs`, the console's one way to split a screen, as Feedback does. In-page chips were tried and dropped: they were a second pattern, and a refresh lost them.

**Ending.** End shows only on a promotion in versions with no new version open. A waiting version would outlive the end, and approving it would run the promotion again.

**Restore.** Restore shows only for a role the manager may give, as the row's own changes do.

**Members.** The list gains KYC, Hours played, City and Member since (month and year). The mobile shows to super admins, in a double share so it stays on one line at 1440 px. With a record open beside it, the list keeps Name, No., Tier, Tonight and Visits; the record has the rest.

**Full numbers.** Keeping the full number from other staff is the list's display only. The record, the search and the member table still give the number to staff who read members (an issue, if the owner wants it enforced).
