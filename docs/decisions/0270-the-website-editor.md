# 0270: The website editor

Date: 28 Oct 2026. Issue #129; features "Website editing"; additions flow 17.

- Staff with `website.edit` choose a page in the console's Website screen. Marketing has `website.edit`, and a super admin has every permission. The page's words are changed in place, block by block. Links, pictures and addresses stay as they are, and a page's blocks are not added to, removed or moved, as there is no page builder.
- **Draft.** Saving makes the page's draft, one a page. The first save keeps what the page showed until then as its first version.
- **Preview.** The draft is previewed by the website itself, at `/preview/<token>`, framed in the console, so it is drawn by the same blocks. The token is the draft's own and is not indexed. The console finds the website at `VITE_WEB_URL`, which is the worktree's website locally. The owner kept the release workflow as it is (#591), so a deployed console says where the preview shows, and saving, scheduling and publishing still work. The practice venue's drafts are never previewed.
- **Publish.** A draft is published now, or scheduled for an IST day and 24-hour time, once the website has tried it and can show it. Saving a scheduled draft keeps the schedule. pg_cron publishes it within the minute. It holds while the venue is frozen. If the scheduler no longer edits the website, or the draft cannot be shown, it goes back to being a draft with one alert. Publishing waits until the edits on screen are saved, and replaces the page's blocks, which the public views read. Two publishes of a page wait for each other, and one version is on the website at a time.
- **Cache.** The website renders each page on request, with no edge cache on its pages, so a publish is live at once and there is no cache to purge. The cache-purge adapter waits for a page cache, if one is added.
- **History.** Every version is kept: each published, and each one it replaced. Publishing an earlier one again makes it a new version, so the history only grows. Versions are the website's content, so a practice reset and a go-live purge keep them, as they keep its pages.
